# Panduan Kontribusi Rozie Toolkit

Terima kasih telah berminat untuk berkontribusi pada proyek ini! Kami sangat menghargai bantuan dari komunitas untuk membuat Rozie Toolkit menjadi lebih baik.

## Cara Memulai Kontribusi

1. **Fork repository** ini ke akun GitHub Anda
2. **Clone** repository fork ke komputer lokal Anda:
   ```bash
   git clone https://github.com/Rozie9103/rozie-toolkit.git
   cd rozie-toolkit
   ```
3. **Buat branch baru** untuk fitur atau perbaikan Anda:
   ```bash
   git checkout -b nama-fitur-anda
   ```
4. **Lakukan perubahan** yang diperlukan dan uji secara lokal
5. **Commit perubahan** dengan pesan yang jelas dan deskriptif:
   ```bash
   git commit -m "Menambahkan fitur: deskripsi singkat fitur"
   ```
6. **Push branch** ke repository fork Anda:
   ```bash
   git push origin nama-fitur-anda
   ```
7. **Buat Pull Request** ke repository utama melalui GitHub

## Aturan Kontribusi

### Kode
- Ikuti **style guide** dan konvensi kode yang sudah ada dalam proyek
- Pastikan kode Anda **terdokumentasi dengan baik** (komentar, docstrings)
- Tambahkan **unit test** untuk fitur baru atau perbaikan bug
- Pastikan semua test **lulus** sebelum membuat Pull Request

### Dokumentasi
- Update dokumentasi jika ada perubahan API atau fitur
- Tambahkan contoh penggunaan untuk fitur baru
- Perbaiki dokumentasi yang kurang jelas atau tidak akurat

### Pull Request
- Berikan **judul dan deskripsi yang jelas** tentang perubahan Anda
- Referensikan issue terkait jika ada (contoh: "Fixes #123")
- Satu Pull Request sebaiknya fokus pada **satu perubahan spesifik**

## Proses Review

1. Maintainer akan mereview Pull Request Anda
2. Mungkin ada permintaan perubahan atau perbaikan
3. Setelah disetujui, kontribusi Anda akan di-merge ke proyek

## Komunikasi

- Gunakan [GitHub Issues](https://github.com/Rozie9103/rozie-toolkit/issues) untuk melaporkan bug atau mengusulkan fitur baru
- Diskusikan ide besar terlebih dahulu sebelum memulai pekerjaan
- Bergabunglah dengan komunitas kami di:
  - Discord: [link-discord]
  - Telegram: [link-telegram]

## Pelaporan Bug

Saat melaporkan bug, mohon sertakan:
- Langkah-langkah untuk mereproduksi bug
- Perilaku yang diharapkan vs yang terjadi
- Screenshot jika memungkinkan
- Informasi lingkungan (OS, versi Python, dll)
